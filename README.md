# 📌 Project Overview

The AI Poll Results Visualizer is a professional Data Visualization and Sentiment Analysis Dashboard developed using Python, Streamlit, Plotly, Pandas, and NLP techniques.

This dashboard analyzes poll response data and generates interactive visual insights including:

- 📊 Poll Result Visualization
- 📈 Response Trend Analysis
- 🧠 Sentiment Analysis
- ☁️ WordCloud Generation
- 📍 Region-wise Insights
- 🖥️ Interactive Dashboard Analytics

The system transforms raw poll data into meaningful business and user insights through modern data analytics techniques.

---

# ❗ Problem Statement

Traditional poll systems often fail to provide:

- 📉 Interactive analytics
- 🧠 Sentiment understanding
- 📊 Clear visual insights
- 📈 Trend monitoring
- 🌍 Region-wise analytics

Manual analysis of large poll datasets is time-consuming and inefficient.

This project solves these issues by providing an AI-powered analytics dashboard with real-time visualizations and intelligent insights.

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/poll-results-visualizer.git
```

---

## 2️⃣ Open Project Folder

```bash
cd poll-results-visualizer
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Streamlit App

```bash
streamlit run app/app.py
```
